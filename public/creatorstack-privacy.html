Privacy Policy

VT CreatorStack

Last updated: 2 November 2026

Operator and purpose

VT CreatorStack is a private YouTube publishing and analytics workspace operated by Valentin Torassa Colombero in Rosario, Argentina. It is used only by the operator, and only for his own YouTube channels, VT Security (@vtcibersecurity) and VT Art (@vtartisan). It has no other users, offers no accounts and is not a public service. VT CreatorStack uses YouTube API Services.

Google and YouTube data accessed

When the operator connects one of his channels, the application asks Google for these permissions:

  • youtube.readonly: read channel, playlist and video information.
  • youtube.upload: upload videos to the connected channel.
  • youtube.force-ssl: manage the channel's videos, playlists, captions and comments.
  • yt-analytics.readonly: read YouTube Analytics and YouTube Reporting API reports for the channel.

With them it retrieves the channel's videos and their metadata (titles, descriptions, publish times and privacy status), public statistics such as view, like and comment counts, the comments posted on the operator's videos together with the public display names of their authors, and the analytics and reports the YouTube APIs return for the channel. It does not request the operator's Google contacts, email, or data from other Google services.

How the data is used

The data is used only for the operator's own work on his channels: uploading and scheduling videos; editing titles, descriptions and publish times; deleting his own private uploads when he replaces them; drafting and publishing replies to comments on the operator's channels; posting the first comment on a new upload; keeping a publishing calendar so that no day is booked twice; and recording how each video performs over time for his dashboards.

When the operator edits a description, links to his own websites can carry a short source tag (such as ?ref=yt-desc) so he can see which videos send visitors to them. This is an operator setting and can be turned off.

VT CreatorStack's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Service providers

VT CreatorStack relies on outside AI services for some features. For drafting and publishing replies to comments on the operator's channels, the comment text, the commenter's display name and the video title are sent to Anthropic's API, and the tool's planning assistant sends Anthropic the titles and statistics of the operator's own videos. The operator's coding assistants, Anthropic's Claude Code and OpenAI's Codex, can also read the tool's own endpoints on his behalf, for example his channels' analytics and publishing calendar. This data is shared with these providers only to provide these features to the operator; it is not sold and is not shared for advertising. Under Anthropic's commercial API terms, data sent through its API is not used to train its models. Apart from these providers, Google itself and the backup storage described below, YouTube data is not transferred to anyone.

Where the data is stored

OAuth credentials and YouTube data are stored on the operator's own server, where the tool runs; on the operator's laptop, which keeps a mirror of channel metrics for analysis; and in backup copies of the server, kept on a backup disk in the same server and off site in cloud object storage and a cloud drive account controlled by the operator, both encrypted at rest by their providers. OAuth credentials are kept only on the server and in its backups.

The workspace's web interface keeps the access token it uses in memory only, and stores its settings, such as the OAuth client ID, and cached interface data in the browser's local storage on the operator's own device. VT CreatorStack does not set advertising or tracking cookies and does not let third parties store or read information on the device.

Retention

Authorized analytics and reporting data, meaning the YouTube Analytics and YouTube Reporting reports for the operator's channels, is kept while the operator's authorization is in place, and the tool re-checks that authorization at least every 30 days. Public statistics of the operator's videos (view, like and comment counts) are kept for up to 36 months as derived performance metrics. Titles, descriptions, comment text and other metadata are refreshed or deleted within 30 days. OAuth credentials are kept only while the channel stays connected. Backup copies are never restored to bring back deleted data, and they are removed as the backups rotate, within 12 months.

Revocation and deletion

Access can be revoked at any time on Google's third-party connections page (https://myaccount.google.com/connections). The operator can also disconnect a channel from VT CreatorStack itself, which revokes the token and deletes the stored token and the data derived from it within 7 days. If access is revoked from the Google account settings instead, the stored data is deleted within 30 days. Data is also deleted within 7 days of a deletion request sent to the address below. Deleting data from VT CreatorStack does not delete it from YouTube.
