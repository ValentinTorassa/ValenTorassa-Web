prueba 3 · el informe

Una página. Seis filas.

INFORME · UNA PÁGINA

Acceso cruzado a documentos (lab)

Laboratorio local con cuentas y datos ficticios. No es experiencia laboral.
HALLAZGO
Un usuario autenticado puede leer el documento de otro cambiando el ID.
EVIDENCIA
Con el token de Gollum, GET /docs/2 (de Frodo) responde 200 con el Anillo.
ALCANCE
Endpoint de lectura /docs/<id> en un entorno local.
DECISIÓN
Comprobar el permiso sobre el documento pedido en cada solicitud, no solo que el token sea válido.
VERIFICACIÓN
Después del cambio, el acceso propio da 200 y el cruzado da 403.
LÍMITE
No se evaluaron edición, borrado ni otros endpoints.
